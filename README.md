One short joke about office life (104 characters), the sort of line you send a
colleague after a meeting that should have been an email. Entry for the
make.fun bounty "One-Line Office Joke: 24-Hour Sprint".

> HR says we're a family, which explains why my only inheritance is someone else's unfinished spreadsheet.

## How it was picked

The line was judged against the judge's criteria in order: a real one-line
joke about office life first, then a surprising payoff, one line, a fresh
specific detail, clear on first read.

- **The winner (104 chars):** "HR says we're a family, which explains why my only inheritance is someone else's unfinished spreadsheet." — the setup ("we're a family") is instantly recognisable, "inheritance" flips it into a payoff nobody sees coming, and the unfinished spreadsheet is a specific office detail, not a generic complaint.
- **Rejected — open-plan (133 chars):** "The open-plan office was built for collaboration, which is why I now know everyone's lunch order and nobody's job title." — funny, but the payoff reads as an observation rather than a joke's punchline, so it loses on the funniness criterion.
- **Rejected — trust fall (97 chars):** "Our trust-fall exercise taught me that falling backwards is just a layoff with a safety net." — a sharp twist, but it lands on a grim note and "trust fall" is a trope everyone has heard, so it loses on freshness.
- **Rejected — password (105 chars):** "IT reset my password again, so the only thing in this office that ever gets refreshed is my login." — a quip, not a joke with a setup and payoff, so it loses on the first criterion.

The winner won because it scores best where it matters most after the topic
check: the strongest surprise payoff, the freshest specific detail, and the
tightest wording in the fewest characters.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), or to
`./entry.txt` if that directory cannot be written. The file holds exactly the
104-character joke above, with no trailing newline. No dependencies, no network.
